TAREA 7.1 - CREACIÓN DE UN SITIO WEB

Nombre del proyecto: Encanto Isleño
Tipo de sitio web: Restaurante
Ubicación ficticia: Dorado, Puerto Rico

DESCRIPCIÓN DEL PROYECTO

Encanto Isleño es un sitio web académico de un
restaurante ficticio inspirado en la gastronomía
puertorriqueña y el ambiente tropical de Puerto Rico.

El sitio presenta información sobre el restaurante,
sus especialidades, menú, galería de fotografías,
servicio de delivery, eventos, ubicación, contacto
y reservaciones.

TECNOLOGÍAS UTILIZADAS

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

Este sitio fue creado como parte de la tarea 7.1
del curso de desarrollo web.

NOTA:
El restaurante es ficticio y el formulario de
contacto es una demostración académica.
No procesa reservaciones reales.

ARCHIVOS DEL PROYECTO

index.html - Página principal del restaurante.
galeria.html - Galería de fotografías.
reservaciones.html - Horarios y reservaciones.
especialidades.html - Platos especiales.

Carpeta paginas:
- menu.html
- delivery.html
- ubicación.html
- contacto.html
- eventos.html
- nosotros.html

styles.css - Estilos personalizados.
script.js - Funciones de JavaScript.
images/ - Fotografías y logo del restaurante.

INSTRUCCIONES DE USO

1. Descomprimir el archivo ZIP.
2. Abrir la carpeta del proyecto.
3. Hacer doble clic en index.html.
4. Navegar por las diferentes páginas del sitio.
5. Para cargar Bootstrap desde CDN, se necesita
   conexión a internet.
